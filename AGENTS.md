# Emotional Microfilms

Read `.github\skills\emotional-microfilm\SKILL.md` before creative or production work.
This project is independent of the existing InterviewReel checkout.
All instructions, skills, reviewers and roadmap state for this project live in
this repository only. Do not create personal/global skill pointers or add its
creative rules to global memory/knowledge files.

All hosts use [the common integration/handoff contract](docs/agent-integration.md).
Claim a workspace and set `FILM_OWNER` before CLI writes; transfer explicitly.
Keep personal `*-user` and explicitly authorized `*-delegated` decisions distinct.
Legacy delegated records under user labels are history, not human acceptance.
Require the [Wow & Enjoyment Analyst](docs/entertainment-review.md) on actual
final playback; no dopamine measurement or audience result is inferred.
Use `microfilm-production-direction` and `microfilm-sound-direction` for every
new production. Export coordinated topic/version bundles, not flat loose files;
see [bundle layout](docs/production-bundles.md). Require actual
`audio-scene-fit` listening review before sound approval/assembly and on the
final asset set. Heavy/mismatched music fails even when technical meters pass.
Prioritize reusable workflow repairs over cosmetic rerolls; preserve good media.

- Ask before writes outside an already approved scope. Never delete existing work.
- Research, model forms and quotes are free reads; generation, reference uploads,
  purchases, publication, commits and pushes require their own explicit approval.
- Do not infer approval to spend from "invest", "workflow", a positive rating,
  selecting a story, an account balance, or a proposed monthly allocation.
- Use Agency defaults. No custom controller. Delegate only bounded independent
  research when requested; use GPT-family agents for delegated reasoning.
- The project contains no paid-generation client, API secrets or automatic upload.
- Follow `docs\visual-development.md`: generate real cast references, show them
  for personal user or explicitly scoped delegated acceptance, then develop
  real scene images and obtain acceptance through the same honest authority path.
  Sketches are not production keyframes. Lock script/hook/timing/transitions,
  lighting/shadows, atmosphere/effects and sound route together before motion.
  Consider beauty/nature accents deliberately, not as a compulsory overlay.
- Generate and inspect every required keyframe before any video job. Motion must
  use the genuine approved per-shot frame references; never substitute text-only
  video or newly invented IDs. Check live limits and exact parameter combinations
  before spending; use `docs\generation-preflight.md`.
- Keep original source summaries, not copied articles/books or copyrighted media.
- A score is an editorial hypothesis, not a forecast or measured audience response.
- Update existing canonical files. Do not create versioned duplicate playbooks.
- Use Node built-ins; no dependency installation is needed for checks and tests.
- Run `npm run check`, `npm test`, and `npm run validate` after workflow changes.
  Ask before expensive rendering or full production experiments.
- Preserve job IDs and asset hashes in ignored `workspace\` production manifests.
  Do not commit signed media URLs, reference uploads or private reviewer identities.
- Report exactly what was tested. No generated film or model quality is validated
  merely because a schema, storyboard, prompt or assembly plan passes.
- Pacing is a required packet and final-review dimension: hook, information
  progression, payoff exposure and ending rhythm must be explicit. Connection-led
  stories require reveal/response/hold; justified poetry or punchline endings may not.
- Visual-first is the default, not a ban on text-led memes. Explicit text-led
  packets require original text, composition/render stage and muted phone-readability proof.
- Lighting/shadow plans are required; inspect caster/receiver direction, contact
  grounding, source changes and temporal consistency in actual motion.
- Maintain multiple genres and visual styles. Universal stories may use subtle
  local details; do not force every concept into a tearjerker or twist.
- For nostalgic/modern songs and singing use the project song-adaptation skill;
  tempo, perceived pace, phrase integrity and rights are separate decisions.
- For an input reference/Reel use the project reverse-engineering skill. Keep
  media and source-specific scripts private in ignored workspace; never mark a
  contact sheet as full playback/listening or an inaccessible URL as ingested.
- On resuming, read `data\roadmap.json`, relevant `data\workflows.json` entry,
  `data\feedback.json`, and the selected workspace manifest before new work.
