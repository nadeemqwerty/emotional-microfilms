## Repeatable exit policy

Use the `critic-loop` workflow. Map original asks to actual artifacts; include new
scope before closing. Give critics exact version/artifacts and a bounded objective.
Repair substantive functional or contractual defects, add focused regressions,
and ask the same critics to verify corrections. Optional taste/preferences are
not endless blockers. Persist findings, actual test evidence and residual limits.

Green requires no unresolved substantive defect **within the stated scope**,
passing project checks, and verified commit/push when authorized. Missing real
film/audio/viewer evidence remains a later BLOCKED production gate, not a fictional
PASS. No current scenario selection, spend, creative generation or publication is
authorized by an audit verdict.
