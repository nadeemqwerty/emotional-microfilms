## Updating the operating system

For each new useful finding: add/refresh the source and its evidence class, change
the smallest relevant rule/packet field, add a reviewer question, and add a focused
test if the invariant is machine-checkable. Record whether it is measured,
vendor-stated or a project hypothesis. Do not silently overwrite contrary results.

`data\roadmap.json` tracks progress; `data\workflows.json` defines repeated
processes. Reviewer agents are read-only and project-local; definitions do not
launch them, confer spend permission or prove they ran.
